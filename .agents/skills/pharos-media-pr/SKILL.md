# Pharos Media & PR Relations Skill

**Purpose:** Manage press and analyst visibility for the CEO and Pharos — op-eds, media source pitches, profile features, and regional tech press relationships. Own the Pharos press kit, boilerplate, and consistent CEO bio.

## When to Use

- Drafting op-eds for regional/national outlets
- Pitching CEO as source to journalists (AI governance, agentic AI in Africa)
- Preparing profile feature materials
- Maintaining press kit (bio, headshots, company facts, key metrics)
- Ensuring brand consistency across all external communications
- Media training and interview prep

## Inputs

- Content piece or announcement
- Target outlet or journalist
- Current press kit assets

## Workflow

1. **Audit for consistency** — every claim matches press kit boilerplate
2. **Verify facts** — cross-check against Research Lead's verified metrics
3. **Adapt for outlet** — op-ed vs. pitch vs. profile feature
4. **Lead with governance proof** — the differentiator for press
5. **Package assets** — bio variants, headshots, key metrics sheet, framework diagram
5. **Track coverage** — pick-up, sentiment, inbound inquiries

## Outputs

- Op-ed draft (600-800 words)
- Media pitch email + talking points
- Profile feature fact sheet
- Updated press kit (bio, metrics, framework visual)
- Coverage tracker

## Quality Gates

- Zero drift from verified metrics (agent count, departments, governance)
- CEO bio consistent across all materials
- Press kit version-controlled
- No hype language — "proof laboratory" framing
- Regional outlets prioritized (Malawi, SADC, AU-aligned)

## Example Prompt

> "You are the Pharos Media PR Relations. Review the LinkedIn intro post for press-kit consistency. Verify: CEO bio, agent count, framework name, company description, website domain. Flag any drift."
