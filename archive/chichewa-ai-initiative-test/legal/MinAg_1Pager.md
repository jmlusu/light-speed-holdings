# MINISTRY OF AGRICULTURE, MALAWI — 1-PAGE PARTNERSHIP SUMMARY
## MoU → MSA for National AI Agricultural Advisory Platform

**Partner Profile:** Government of Malawi | **Decision Makers:** Hon. Sam Kawale (Minister), Dr. Godfrey Chingoma (PS)
**Mandate:** Malawi 2063 Pillar 1 | Digital Malawi Project (P173456, $100M IDA) | AIP Subsidy Program (3.5M farmers)
**Current Gap:** 2,000 officers for 3.5M farmers (1:1,750) | Advisory: radio/SMS only | Subsidy verification: manual

---

## THE DEAL

| Element | Terms |
|---------|-------|
| **Structure** | MoU (18 months) → **Master Services Agreement (3+2 years)** |
| **Phases** | Pilot (50 farmers, 3 districts) → District Scale (10K, 10 districts) → National (100K+, 28 districts) |
| **Our Investment** | $2.5M Phase 1 (platform + model) — internal + WB/Gates grants |
| **Govt Contract (Y2+)** | **$600k/yr** target: Platform ($300k) + IVR ($150k) + Dashboard ($100k) + Training ($50k) |
| **WB Co-Financing** | 50/50 IDA/Govt via Digital Malawi restructuring (Light Speed supports proposal) |
| **IP** | Platform = LS; **Model = National Asset (Govt)**; Agent defs = Joint; Govt data = Govt |
| **Data** | Govt = Controller; LS = Processor; Malawi DPA 2024 compliant; Primary storage in Malawi |
| **Capacity Building** | **50 Malawian ML engineers trained** (curriculum + apprenticeships) |

---

## WHY MINISTRY SAYS YES

| Pain Point | Our Solution |
|------------|--------------|
| Extension officer shortage | **AI copilot** → 1 officer serves 500+ farmers via WhatsApp/IVR |
| AIP leakage/fraud (30%+) | **Toll-free IVR (*384#)** → Instant eligibility + depot stock + complaints |
| No real-time policy data | **Ministry Dashboard** → Adoption, crop alerts, yield forecasts, officer activity |
| Language barrier (Chichewa) | **Native Chichewa AI** (not translated) + voice for feature phones (70% of farmers) |
| Youth disengagement from farming | **Modern digital tools** → Agriculture as tech-enabled career |
| Donor dependency | **Revenue model** → Platform fees + API + regional licenses → sustainability |

---

## KEY NEGOTIATION POINTS

| Issue | Our Position | Likely Govt Position | Compromise |
|-------|--------------|-------------------|------------|
| **Model Ownership** | Commercial license | Full Govt ownership | **National Asset** — Govt sovereign rights; LS commercial license worldwide |
| **Data Sovereignty** | Hybrid (Malawi primary, EU backup) | Malawi-only | **Malawi-primary**; EU backup only if local infra insufficient |
| **Procurement** | Single-source (unique platform) | Competitive tender | **WB single-source justification**; MSA via PPPC Act |
| **Contract Currency** | USD (indexed) | MWK | **USD indexed at signing rate**; MWK option at prevailing rate |
| **Termination** | 90-day cure | Shorter | **90-day cure**; Force majeure 120 days |
