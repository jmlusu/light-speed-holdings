## Root Cause (filled by the resolving engineer)

Three independent causes, discovered in this order:

1. **Test (ubuntu-latest) and Test (windows-latest) failed on the same assert.**
   Commit `67d88031` (token-consumption audit) lowered
   `LoopConfig.max_iterations` from 10 to 5 in
   `src/ai_company/executor/agent_loop.py:95`, but
   `tests/unit/test_agent_loop.py::TestLoopConfig::test_defaults` was never
   updated and still asserted `config.max_iterations == 10`. Both matrix legs
   therefore failed with `assert 5 == 10`. The test was the stale artefact, not
   the implementation.

2. **ECL Harness Lint failed with "Missing harness/changes/active".** The
   directory was deleted in `917dbb96` (the multimodal asset factory merge).
   Git cannot track an empty directory, so a clean checkout had no `active`
   slot, and `scripts/maintenance/lint-ecl.ps1` requires `active`, `parking`
   and `archive` to exist.

3. **`opencode.json` on the branch was broken and would have shipped.** The
   branch had blanked every direct-provider `baseURL` (Groq, NVIDIA, Mistral,
   Google AI Studio, Cloudflare, Ollama Cloud) and dropped the local Ollama and
   llama.cpp model lists. Merging it would have broken provider routing on
   `main`. This was not a CI failure, because no check validates provider
   configuration.

Separately, the branch carried 15 ad-hoc scratch artefacts. None were
referenced by code, tests, or workflows, so they were dead weight rather than a
functional defect.

## Fix (filled by the resolving engineer)

1. `tests/unit/test_agent_loop.py` — `test_defaults` now asserts
   `max_iterations == 5`, with a comment naming `67d88031` as the commit that
   changed the default, so the next reader can trace it.
2. Added `harness/changes/active/.gitkeep` (with an explanatory header) so the
   ECL path survives a clean checkout.
3. Restored `opencode.json` to `origin/main` byte-for-byte
   (`git checkout origin/main -- opencode.json`).
4. Removed the scratch artefacts: `bogus-token.json`, `no-token.json`,
   `payload.json` (ad-hoc contact-form curl fixtures), `gitlog_recent.txt`,
   `results.csv`, `results-cloud.csv`, `results-nvidia.csv`, `status/`
   (model-status dumps), `Check-ModelStatus.ps1`, `Run-ProviderTests.ps1`,
   `Test-OpencodeModels.ps1`, `verify_status.py`,
   `opencode.json.bak_28october2026`.
