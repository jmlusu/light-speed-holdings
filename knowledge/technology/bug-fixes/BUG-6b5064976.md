CI check "Site Build + Principles Gate" (run 45028048831) failed with two
stale assertions in `src/pages/_tests__/WhatWeDoPage.test.tsx`:

- `getByText(/Human Direction/)` matched multiple elements.
- `getAllByRole('row')` found no rows.

## Root Cause (filled by the resolving engineer)

The WhatWeDoPage UI was refactored to interactive pillar/lifecycle panels
(`OperatingModelOverview`, `DeliveryLifecycleSection`), so pillar names now
appear in both a selector and a detail panel and the old engagement-model
`<table>` no longer exists. The tests still queried the pre-refactor DOM.
Separately, `tsconfig.json` used `baseUrl` with non-relative `paths` entries.

## Fix (filled by the resolving engineer)

- Removed `baseUrl` and converted all `paths` targets to `./`-relative form.
- Changed the pillar-name assertion to `getAllByText(...)` with a length check.
- Replaced the obsolete `role="row"` query with assertions on the rendered
  stage content (`Problem Addressed`, `Design Target Operating Model`).
