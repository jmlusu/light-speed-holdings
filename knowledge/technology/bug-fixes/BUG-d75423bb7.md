# Captured bug records wrote the literal text ${sha} instead of the commit hash

**ID:** BUG-d75423bb7
**Date:** 2026-09-25
**Resolved:** closed
**Commit:** `d75423b`
**Issue:** (none - conventional-commit fix: without an issue reference)

## Symptom

Auto-generated records under `knowledge/technology/bug-fixes/` contained a **Commit** line reading literally:

```
**Commit:** ${sha}
```

instead of the resolved commit hash.

## Root Cause

`scripts/capture-fix.ps1` builds the record inside a double-quoted here-string (`@"..."@`). Variables were written with a leading backtick — `` `${sha}` ``, `` `${title}` `` — which PowerShell treats as an escape, so the `$` was emitted literally and no substitution occurred. Fields written without the backtick (`${Issue}`, `${date}`, `${state}`) expanded correctly, which is why some lines were right and others were not.

## Fix

Removed the backticks so every variable (`$sha`, `$title`, `$body`, `$state`, `$subject`) expands normally inside the here-string. `capture-fix.ps1` also gained a conventional-commit fallback: commits whose subject matches `^fix(\([^)]*\))?:` and reference no issue are captured under a record id derived from the 9-character short SHA, so fix commits are no longer silently dropped.

## Files Changed

`scripts/capture-fix.ps1`

## Diagnostic Commands

```powershell
Select-String -Path knowledge\technology\bug-fixes\*.md -Pattern '\$\{sha\}'
```
Any match is a record generated before this fix.

## Verification

`BUG-d75423bb7.md` and `BUG-84e037f13.md` (generated after the fix) carry a full 40-character SHA; `BUG-93e21736a.md` was generated before and still showed `${sha}` until it was filled in manually. The record for this very commit is itself generated by the fixed script.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/capture-fix.ps1
```

## Pattern

In PowerShell, a backtick before `$` suppresses substitution. Inside double-quoted here-strings, write `$var` (or `${var}`) without a leading backtick — and never emit a template placeholder from a script that had the value available.
