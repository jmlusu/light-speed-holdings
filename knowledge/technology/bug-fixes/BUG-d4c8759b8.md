## Root Cause (filled by the resolving engineer)

Three separate defects compounded:

1. 35 images were referenced as plain string literals (`/src/assets/images/x.jpg`)
   in `src/components/**`, `src/data/siteContent.ts` and `src/pages/**`. Vite only
   hashes and emits an asset reached through `import` or a CSS `url()` it can
   resolve; a string is copied verbatim. The files therefore never shipped, and
   `vercel.json`'s SPA rewrite (`/(.*)` -> `/index.html`) answered every request
   with `200 text/html` instead of a 404, so the breakage was invisible to status
   codes alone.
2. `src/__tests__/media-registry.test.ts` checked those literals for *existence on
   disk* and treated that as proof, so all 35 passed while being broken in
   production. The same regex also omitted `avif`, hiding 14 further references.
3. The source files were 655-1254 KB JPEGs, so even a working path would have
   broken the per-kind budgets in `docs/IMAGE_STRATEGY.md` (#385, Decision 2:
   hero <= 150 KB, thumbnail <= 30 KB). No variant-generation step existed.

## Fix (filled by the resolving engineer)

- Added `scripts/maintenance/generate-media-variants.mjs` (sharp-based, additive
  only, fails the run if a variant exceeds its 150 KB budget).
- Generated 35 AVIF variants into `public/assets/images/`: 38-133 KB each,
  2.27 MB total, against 28.8 MB of source JPEGs.
- Rewrote all 41 references across 13 files to `/assets/images/*.avif`.
- Repointed `ClosingCTASection`'s `/hero-background.jpg` CSS background, which
  pointed at a file that never existed, at an existing hero variant.
- Registered the 35 paths in `src/data/registries/media-registry.json` and removed
  3 entries that no longer described anything rendered.
- Hardened the guard: the `/src/assets` quarantine is empty and the rule is now
  absolute; a 150 KB weight budget is enforced.

## Verification

- `npx tsc --noEmit` -> exit 0.
- `npx vitest run` -> 149/149 across 16 files.
- `npx vite build` -> emits 35 AVIF (2.27 MB); zero `/src/assets/` strings remain
  in `dist/assets/*.js`.
- Preview server on the assigned preview port: all 35 paths returned `200` with
  `content-type: image/avif`; the real browser fetched the 5 above-fold variants
  at `200`.
- Both new guard rules were probed into failure (a reintroduced literal, and a
  budget lowered below the real sizes), confirmed to fail with their intended
  messages, then reverted.
