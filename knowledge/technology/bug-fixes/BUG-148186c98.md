## Root Cause (filled by the resolving engineer)

PR #433 (commit 794e793b) repaired a conflict-corrupted `src/App.tsx`
(commit message: "restore 7 page imports in src/App.tsx dropped during
conflict resolution") but the rewritten route table dropped three
entries that existed at 67f87b72: `proof` (Navigate -> /use-cases),
`ask` (Navigate -> /contact), and the `*` -> NotFoundPage catch-all.
The repair kept the `NotFoundPage` import (App.tsx:16) while removing
its only usage, and no `errorElement` exists anywhere, so the loss is
collateral from conflict resolution rather than a product decision.
Impact: 5 live components still link those routes (AskLightSpeed x2,
ProofSection, VisitorPathsSection -> /proof; InsightArticlePage,
VisitorPathsSection -> /ask), so those clicks and every unknown URL
rendered a blank page.

## Fix (filled by the resolving engineer)

Restored the exact 67f87b72 semantics in the route table: `proof` ->
`<Navigate to="/use-cases" replace />` (ProofPage superseded by
UseCasesPage per the Directive §10 comment at UseCasesPage.tsx:4;
ProofPage.tsx is dead legacy, not routed), `ask` ->
`<Navigate to="/contact" replace />`, `*` -> `<NotFoundPage />`.
`Navigate` and `NotFoundPage` were already imported.
