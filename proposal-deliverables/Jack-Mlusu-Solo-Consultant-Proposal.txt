PROPOSAL SUMMARY
================================================================================

Light Speed Holdings proposes a complete USSD service lifecycle—menu design,
development, deployment, and 24-month maintenance—on short code 54747, delivering
health information to women in Balaka and Lilongwe districts in Chichewa.

Our team combines deep USSD technical expertise with local Malawi knowledge and
international health program experience. All team members are full-time Light Speed
Holdings staff—no subcontracting.

Key deliverables:
• USSD menu design and deployment on short code 54747 (TNM + Airtel networks)
• User Acceptance Testing with minimum 20 participants from target demographics
• Data pipeline integration connecting USSD interactions to VillageReach monitoring
  systems via REST API
• Monthly uptime and usage reporting with ≥99% availability target
• Training and handover documentation for VillageReach technical staff
• 24-month post-launch maintenance and support commitment
• Completion report at end of engagement summarizing outcomes and recommendations

Technical constraints (USSD protocol):
• Maximum 182 characters per USSD screen—every word must earn its place
• Number-driven navigation only (1, 2, 3…); no free-text input on menu screens
• "99. Main Menu" must appear on every screen for consistent back-navigation
• Maximum four menu levels deep to prevent user fatigue and drop-off
• Chichewa-language content requiring culturally appropriate health messaging

Budget structure:
• 40% ($18,000) at contract signing
• 20% ($9,000) at go-live on 54747
• 40% in monthly installments during the 24-month maintenance period
• Effective rate: ≈$1,875/mo all-in

Compliance:
• Alignment with Malawi Data Protection Act (2024)
• GDPR best practices
• VillageReach internal data governance policies

Data Privacy:
• USSD data minimization: collect only minimum data required for service delivery;
  no PII stored on USSD screens unless explicitly authorized
• All data in transit encrypted via TLS 1.3
• REST API endpoints secured with OAuth 2.0 token authentication
• Role-based access control (RBAC) for all system components; principle of least
  privilege enforced
• Complete audit trail of all data access and modifications; logs retained for 12

  securely deleted; no permanent storage of user phone numbers
• Documented incident response plan with 24-hour notification commitment for any
  data breach affecting VillageReach systems

Short Code 54747:

• No regulatory concerns; properly accredited and registered for use
