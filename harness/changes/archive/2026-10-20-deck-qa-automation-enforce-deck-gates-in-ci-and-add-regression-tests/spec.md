# Spec

- Intake type: Structured Change
- Input shape: requirement-first (audit findings list the gaps; each becomes a task)

## Goal And Evidence

- Real problem or user request: the AI Venture Studio client deck is generated code, but nothing in CI checked it. A read-only audit of PR #480 (merged as `359e4b0b`) found the following gaps: the verifier and the rendered-pixel gate were manual-only (not wired into CI or pre-commit), there was no pytest regression test for the logo-over-tagline defect fixed in PR #480, no ECL change record existed for that work, and `docs/STATUS.md` / `CHANGELOG.md` had no entry for it. The audit also found the same design constants hardcoded in three files, a stale-cache risk in the logo crop, no source-size validation on the brand asset, and that the cover slide was never pixel-checked.
- Current behavior: `scripts/presentation/verify-venture-studio-deck.py` (11 checks) and `scripts/presentation/render-venture-studio-deck.py` (rendered pixels via LibreOffice) run only when a human invokes them. `scripts/presentation/generate-ai-venture-studio-deck.py`, the verifier and the render gate each hardcode the lockup geometry separately.
- Source of evidence: verification-only audit of the merged state (2026-10-20) with independent re-execution of both gates against the shipped deck and against the pre-fix deck; `docs/ECL.md` §2; `.ai-company/constitution/10-DEFINITION-OF-DONE.md` C-9, C-10, D-5, D-7.

## User Scenarios And Success

- Primary user/system scenario: a client deck is edited or regenerated and the change is proposed. A reviewer must not have to trust that the logo still lands correctly; CI must fail the change if the logo overruns its frame, loses its clear space, or the committed deck drifts from the generator.
- Success criteria:
  - `Deck QA (structure)` and `Deck QA (rendered pixels)` run on every PR and are wired into the `CI Gate` aggregate, so a deck regression blocks the merge.
  - A pytest suite reproduces the PR #480 defect class and fails on the pre-fix geometry.
  - The committed deck is checked against the generator output, so a hand-edited or stale deck fails CI.
  - The generator, the verifier and the render gate read the same design constants.
  - The generator refuses a brand asset whose size does not match the expected source size, and cannot ship a stale cached crop.
  - The cover slide is pixel-checked like the closing slide.
  - ECL record, `docs/STATUS.md` and `CHANGELOG.md` reflect the change.
- Acceptance criteria: `ruff check` clean on the touched files, `pytest tests/presentation` green, the verifier reports `ALL 11 CHECKS PASSED` on the rebuilt deck, the render gate reports `ALL RENDER CHECKS PASSED` on the rebuilt deck and fails on the pre-fix deck, `lint-ecl.ps1` and `check-index-freshness.ps1` pass, and CI is green on the PR.

## Non-Goals

- Changing the deck's content, wording, palette, type scale or slide count.
- Rebuilding the deck's design; the layout stays as merged in PR #480.
- Making the render gate run on Windows agents (CI uses ubuntu-latest, where `soffice` is a console binary).
- Changing `pyproject.toml` dependencies (PyMuPDF stays an ad-hoc `uv run --with` overlay so `uv.lock` does not change).

## Constraints

- `main` is protected: branch, PR, all required checks green before merge.
- The primary working copy holds an unrelated staged changeset and must not be touched; all work happens in a separate worktree.
- ECL allows one active change. The unrelated `haomtgv-blueprint-hero-and-page-wiring` change was parked with the harness script and resumed after this change closed.
- `harness/changes/INDEX.json` is generated by script only.
- The deck gates must keep passing on the committed deck; no gate may be weakened to make a new test pass.

## Assumptions

- The ubuntu-latest runner either has `soffice` preinstalled or can install `libreoffice-impress` from apt; the job installs it only when missing.
- Arial is substituted by a metric-compatible font on CI; the gate therefore measures clearance against the declared tagline top edge rather than the rendered glyph ascent.
- The brand asset `brand/logo/logo-full.png` stays 1254x1254 until someone deliberately changes it, at which point the generator fails loudly and the crop box is updated.
