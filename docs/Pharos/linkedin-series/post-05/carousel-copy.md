# Carousel Copy - Post 5: AI Agents for Malawian SMEs

## Card 1: The SME Question

**Title:** The 90-Agent Intimidation

**Key Point:** The number 90 intimidates SMEs. The wrong question: "How many agents can we afford?" The right question: "How many can we govern?" Start with 8–12, prove the output, then scale.

## Card 2: Eight Products

**Title:** Eight Recurring Revenue Products

**Key Point:** Eight recurring revenue products fund the agent economy per `config/company/kpis.yaml`. Agents exist to serve work with a buyer, internally or externally, which disciplines which agents get built.

## Card 3: Start Small

**Title:** Start with 8–12 Agents

**Key Point:** Define role, scope, and approval tier before any agent runs. The registry is cheap to write and expensive to skip. You cannot govern a population you cannot enumerate.

## Card 4: The Queue

**Title:** One Queue Before Any Agents

**Key Point:** Even a file-backed inbox with leases and a dead-letter path gives you durability, audit, and a place for failure to land. This is days of work, not a platform purchase.
