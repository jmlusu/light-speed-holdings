# Substack Section - Post 4: What the H-A-O-M-T-G-V Framework Actually Means

**Series:** AI-Native Organizations (11 posts)
**Post:** 4

## Monthly Digest Slice

This month's focus: The full H-A-O-M-T-G-V framework that makes LightSpeed's AI-native enterprise work. This issue unpacks all 7 layers: Human Purpose, Agentic Workforce, Orchestration, Models, Tools, Gates, and Verification, and how they interconnect for Malawi and SADC institutions.

### Framework Overview - All 7 Layers

| Layer | Focus | Key Question |
|-------|-------|--------------|
| **H** | Human Purpose | Strategy, ethics, leadership, accountability: who owns the outcome? |
| **A** | Agentic Workforce | What work can AI agents perform? Role-bound, measurable, governed. |
| **O** | Orchestration | How do agents coordinate? Message bus, departments, workflows. |
| **M** | Models run sovereign | Sovereign data defaults, visible variable cost, no lock-in. |
| **T** | Tools stay sandboxed | What tools may agents interact with? 7-tool canonical vocabulary. |
| **G** | Gates approve | Who decides which actions may proceed? Five-tier approval matrix. |
| **V** | Verification records | How do we prove value, not just promise it? Every claim maps to a source. |

### Key Takeaways

- The 7-layer framework is one interconnected system, not a checklist. Each layer depends on the one before it.
- H (Human Purpose) is the constitutional layer: strategy, ethics, leadership stay with named humans.
- A (Agentic Workforce) answers what work AI agents can perform, with clear ownership, measurable engagement, and governed decision-making.
- O (Orchestration) is the operational backbone: one message bus, 20 departments, nine workflow definitions, live org metrics.
- M (Models run sovereign) ensures sovereign data defaults, visible variable cost, and no lock-in: 90-day pilot, per-agent cost visible from week one.
- T (Tools stay sandboxed) enforces the canonical 7-tool vocabulary. No tool, no action. Boundaries are the product.
- G (Gates approve) implements the five-tier approval matrix per action class. Audit log records who, what, when, tier.
- V (Verification records) maps every claim to a source of record. Buyers, regulators, boards can audit without understanding the models.
