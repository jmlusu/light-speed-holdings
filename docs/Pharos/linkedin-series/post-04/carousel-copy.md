# Carousel Copy - Post 4: What the H-A-O-M-T-G-V Framework Actually Means

## Card 1: The Framework

**Title:** H-A-O-M-T-G-V: One System

**Key Point:** The 7-layer framework is not a checklist. Each layer depends on the one before it. No layer is valuable on its own: H → A → O → M → T → G → V.

## Card 2: Human Purpose

**Title:** H: Human Purpose & Authority

**Key Point:** Strategy, ethics, leadership, relationships, and final accountability stay with named humans. Agents are delegates, never principals. Five-tier approval matrix (ADR-017) ensures every agentic decision is reversible and auditable.

## Card 3: Agentic Workforce

**Title:** A: Agentic Workforce

**Key Point:** 90 role-bounded agents in one registry, each with domain scope and permission boundary. Agent Utilization KPI-003 measures engagement. Permissioned tool sandbox: 7 tools only.

## Card 4: Orchestration

**Title:** O: Orchestration

**Key Point:** One message bus. 20 departments own agent capacity. Crash-safe, idempotent task queue. Nine workflow definitions with SLA monitoring. Org metrics as a live graph.
