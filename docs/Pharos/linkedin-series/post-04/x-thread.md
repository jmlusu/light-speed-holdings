# X Thread - Post 4: What the H-A-O-M-T-G-V Framework Actually Means

🧵 We've built an AI-native enterprise with 90 agents across 20 departments, governed by a 5-tier HITL approval matrix. Now: the full framework. Here's how all 7 layers hold together.

1/9 🏗️ H-A-O-M-T-G-V is not a checklist. It is one interconnected system. Each layer depends on the one before it. No layer is valuable on its own.

2/9 H: Human Purpose. Strategy, ethics, leadership, accountability stay with named humans. Agents are delegates, never principals. Five-tier approval matrix (ADR-017) moves every decision: autonomous → HITL-approved → reviewed → snoozed → cleared. Speed without accountability is an incident waiting for a date.

3/9 A: Agentic Workforce. 90 role-bounded agents in one registry. Each with domain scope and permission boundary. Agent Utilization KPI-003 measures engagement. Permissioned tool sandbox: 7 tools only. Everything is scoped. Boundaries are the product.

4/9 O: Orchestration. One message bus. 20 departments as owners of agent capacity. Crash-safe, idempotent task queue. Nine workflow definitions with SLA monitoring. Org metrics as a live graph (capacity/activity/trend/risk, 30s TTL cache). Coordination failures become visible as metrics.

5/9 M: Models run sovereign. DPA 2017/2024 + GDPR by default. No foreign-owned models without in-country safeguards. 8 recurring revenue products fund the agent economy. 90-day pilot, no lock-in, visible variable cost from week one.

6/9 T: Tools stay sandboxed. Canonical 7-tool vocabulary: read, edit, grep, list, bash, webfetch, task. No tool, no action. Anything outside the approved set is rejected. Agent sprawl vs workforce: sprawl grows by screenshots; workforce grows by registry entries.

7/9 G: Gates approve. Five-tier matrix per action class. Tier 1 (autonomous): routine task execution. Tier 2 (HITL-approved): data access, customer-facing outcomes. Tier 3 (reviewed): policy changes, budget reallocations. Tier 4 (snoozed): high-impact deferred. Tier 5 (cleared): treasury movements, external commitments. Audit log records who, what, when, tier.

8/9 V: Verification records it all. Every claim maps to a source of record. Agent utilization → KPI-003 logs. Approval decisions → audit log. Revenue → eight recurring products. Org metrics → computable graph. Model registry → company registry entries. Buyers, regulators, boards can audit the structure without understanding the models.
