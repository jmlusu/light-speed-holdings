## Script Narrative (Full)

"LightSpeed Holdings Limited™ operates a live AI-native enterprise — 90 agents, 20 departments, five-tier human-in-the-loop governance. The hardest question we answer every day is not how capable the models are. It is what may the agent decide. Five tiers: autonomous, HITL-approved, reviewed, snoozed, cleared. Tiers attach to action classes, not agents — the same agent formats autonomously but needs human approval to send. Tier 5 is a wall: secret exfiltration, self-modifying governance, unauthorized tier changes, irreversible commitments without co-signature. A model proposing its own promotion is executing a violation, not making a request. The RACI is one line: the agent is always Responsible, the named human is always Accountable. And we publish the expired-approval count, because if nobody reports unanswered approvals, the human layer is theater. Download the Malawi Agentic AI Monitor to explore how these patterns apply in-Malawi context."
