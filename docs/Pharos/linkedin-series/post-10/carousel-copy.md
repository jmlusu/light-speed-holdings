# Carousel Copy - Post 10: What Should an AI Agent Decide?

**Card structure (per plan §4):** 4 cards: Human-only → Shared → Agent-only → Forbidden

## Card 1: Human-Only

**Title:** Humans Decide

**Key Point:**
- Strategy, ethics, leadership, final accountability (H layer)
- Governance changes: matrix, registry, tier assignments
- Tier promotion: raising an action class to Tier 1
- Accountable party is always a named human

## Card 2: Shared (The Working Middle)

**Title:** Shared Decisions

**Key Point:**
- Tier 2: agent proposes, human approves before execution (external sends, data access, spend in envelope)
- Tier 3: agent executes, human reviews after (customer commitments, contract language)
- Tier 4: paused pending human clearance (new integrations, novel action classes)

## Card 3: Agent-Only

**Title:** Agent Decides

**Key Point:**
- Tier 1 autonomous actions, audited after the fact
- Format normalization, routing, internal drafting, routine status updates
- Earned per action class through measured reliability
- Bounded by the seven-tool sandbox even when autonomous

## Card 4: Forbidden

**Title:** Tier 5: Not Delegable

**Key Point:**
- Secret exfiltration
- Self-modifying governance
- Unauthorized tier changes
- Irreversible external commitments without human co-signature
- A model proposing its own promotion is a violation, not a request
