# Carousel Copy - Post 6: Agentic AI in Health & M&E

## Card 1: The Health Question

**Title:** AI in Health & M&E

**Key Point:** AI in health and M&E is not a separate category. It is AI-native architecture applied to regulation-sensitive domains. The question is not "can AI improve health outcomes?" but "how is the architecture designed?"

## Card 2: Start Small

**Title:** Start with 3–5 Agents

**Key Point:** Define role, scope, and approval tier before any agent runs. The registry is cheap to write and expensive to skip. An SME can start with 3 agents and expand to 12 as the system proves its value.

## Card 3: The Queue

**Title:** One Queue Before Any Agents

**Key Point:** Even a file-backed inbox with leases and a dead-letter path gives you durability, audit, and a place for failure to land. This is days of work, not a platform purchase.

## Card 4: Utilization

**Title:** Utilization from Day One

**Key Point:** If you cannot see which agents are consuming work this week, you are operating on anecdote. KPI-003-style utilization is the cheapest possible sensor.
