# X Thread - Post 6: Agentic AI in Health & M&E

🧵 AI in health and M&E is not a separate category. It is AI-native architecture applied to two of the most regulation-sensitive domains in our region. The question is not "can AI improve health outcomes?" but "how is the architecture designed so agents improve outcomes under sovereign data defaults, visible variable cost, and 5-tier HITL governance?"

1/9 ⚕️ Here is the wrong question, and the right one. Wrong: "Can AI improve health outcomes?" Right: "How is the architecture designed so agents improve outcomes under sovereign data defaults, visible variable cost, and 5-tier HITL governance?" The answer changes everything.

2/9 📉 Why health and M&E feel different. The blank-cheque model: rip-and-replace, multi-year contracts, invisible cost curves, data sent outside country. The AI-native alternative: 90-day pilot, per-agent cost visible from week one, no lock-in, data stays in-country. The cost curve is a dial, not a contract.

3/9 👥 Start with 3–5 agents. Define role, scope, and approval tier before any agent runs. The registry is cheap to write and expensive to skip. An SME can start with 3 agents (data quality checker, KPI pull, compliance monitor) and expand to 12 as the system proves its value.

4/9 📋 One queue before any agents. Even a file-backed inbox with leases and a dead-letter path gives you durability, audit, and a place for failure to land. This is days of work, not a platform purchase.

5/9 📈 Utilization from day one. If you cannot see which agents are consuming work this week, you are operating on anecdote. KPI-003-style utilization is the cheapest possible sensor.

6/9 🛡️ Install the gates before the autonomy. Tier-1 (autonomous) actions only after you have watched the agent operate under review for a period. Autonomy is earned per action class, not granted at onboarding.

7/9 📊 Seven-tool canonical sandbox with domain restrictions. The default is read, edit, grep, list, bash, webfetch, task. But in health: read limited to de-identified records, edit limited to KPI dashboards, webfetch limited to trusted URIs (WHO APIs, ministry portals, peer-reviewed repos).

8/9 💰 Eight recurring revenue products discipline the agent build. In health, the equivalent is a clear economic purpose for each agent. If you cannot name the buyer (government budget line, donor program, facility cost-recovery), the agent does not exist.
