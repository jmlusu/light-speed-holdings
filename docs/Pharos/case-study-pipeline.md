# Proof-of-Work Portfolio (Case Study Pipeline)

Documented, quantified deployments are the credibility engine for the CEO's
thought leadership. Numbers, not adjectives, outperform flashy demos with
policymakers and press. Serve each sector pillar with at least one documented case.

## 1. J&S StopOver Bar — "The World's Smallest AI-Native Bar"

**Status:** priority / most under-used asset.

A real, non-tech SME already running agentic decision support (pricing, via the
CEO's LLM-council methodology).

**Document it as:** problem → agentic approach → measurable outcome.

**Story arc:**

```
Human Business
  → AI Finance Agent
  → AI Inventory Agent
  → AI Procurement Agent
  → AI Operations Agent
  → CEO Dashboard
```

Demonstrates inventory, sales, shortage, cash-reconciliation, procurement and
profitability monitoring — a genuinely African SME AI transformation case study.

## 2. Health / M&E

Composite workflow: monitor clinic supply chains, auto-generate procurement
requests on anomaly detection (dashboard Z-score). Leverages Last Mile Health
credibility and the sector where UNDP/UNESCO already engage.

## 3. VSLA / SACCO / Mobile Money — Financial Inclusion

Agentic workflows over mobile-money rails (Airtel Money, TNM Mpamba) and informal
savings groups. A use case COMESA/IDEA is actively seeking; supports micro-loan
risk assessment for smallholder farmers.

## 4. Lightspeed Holdings — The Meta Case Study

An AI-native consulting/build shop operating in Malawi, documented openly:
143 agents, 20 departments, 5-tier HITL approvals, audit trails, RACI, governance
controls mapped to regulatory requirements.

## Sector Targeting (SADC priorities)

- **Agri-Tech:** weather + soil + mobile-money micro-loan risk assessments; farmer
  advisory integration (e.g. existing Ulangizi-style chatbot).
- **Public Health & Services:** citizen-query agents, legislative summarization,
  case tracking for courts/land registries.
- **SME / Informal:** "Company-in-a-Box" lightweight agent set (Marketing, Sales,
  Compliance, Finance, HR) for Malawian SMEs.
- **Finance / Compliance:** automated audit reconciliation, KYC, cross-border
  trade documentation.
- **Supply Chain / Logistics:** corridor routing and ledger-auditing agents
  (Nacala, Beira corridors).

## Case Study Format

1. Problem / baseline (with a number)
2. Agentic approach (architecture, agents, HITL gates)
3. Measurable outcome (cost/time/yield/procurement leakage, etc.)
4. Governance and auditability (why a risk officer can say yes)
5. Reuse note (what others can replicate)
