# POSITIONING DICTIONARY — LightSpeed Holdings

## Four Core Concepts (Directive §25)

### BASE
- **Definition**: The legally registered headquarters; physical and operational origin
- **Primary term**: Malawi / Lilongwe
- **Must appear on**: Legal pages (Terms, Privacy); Brand footer
- **Claims safety**: ✓ Verified — LightSpeed is headquartered in Lilongwe, Malawi
- **Usage**: "Based in Malawi", "headquartered in Lilongwe", "Lilongwe, Malawi"

### EXPERIENCE
- **Definition**: Where current work/experiments are concentrated; factual project scope
- **Primary scope**: Malawi + African markets where projects have been delivered
- **Examples**: "We have delivered projects in Malawi"; "Our team has worked across Malawi and African markets"
- **Restriction**: Do NOT use "SADC" as a geographic ceiling/limit; use "Africa" for broader scope
- **Claims safety**: ✓ Factual when referencing specific project deliveries

### FOCUS
- **Definition**: The principal market opportunity; the primary addressable region
- **Primary term**: Africa (not "Southern Africa", not "SADC")
- **Must NOT contain**: "Southern Africa" as a standalone positioning term
- **Preferred framing**: "Africa-focused", "African operating realities", "Africa and beyond"
- **Claims safety**: ✓ Africa is the stated focus per company mission

### REACH
- **Definition**: Where LightSpeed is willing and able to work; the operational ceiling
- **Primary scope**: Africa and beyond (no geographic ceiling)
- **Preferred framing**: "Africa and beyond", "globally", "across Africa and international markets"
- **Claims safety**: ✓ Open-ended — no ceiling imposed
- **Usage**: "We work across Africa and beyond"; "globally distributed expertise"

## Positioning Hierarchy

```
BASE              →  EXPERIENCE              →  FOCUS              →  REACH
Malawi/Lilongwe   →  Malawi + African markets  →  Africa (primary)  →  Africa and beyond
```

## Claims Safety Review

### Always Safe (Preserve)
- ✓ "headquartered in Lilongwe, Malawi" (BASE — verified)
- ✓ "Lilongwe, Malawi" in legal/contact pages (legal requirement)
- ✓ "Malawi Data Protection Act" (SPECIFIC CONTEXT — legal fact)
- ✓ "University of Malawi" project references (SPECIFIC CONTEXT — verified)
- ✓ "Malawi payment rails" (SPECIFIC CONTEXT — verified)
- ✓ "Proof" / "PILOT" / "PROVEN IN-HOUSE" honesty badges
- ✓ "AI executes. Humans decide." (governance principle)
- ✓ Zero-Cloud Boundary / offline-first architecture claims
- ✓ Human CEO / human accountability model

### Review Before Use (Context Dependent)
- ✗ "across Malawi, SADC, and Africa" → review for ceiling
- ✗ "built for Southern Africa" → replace with "African operating realities"
- ✗ "SADC-first" / "SADC-focused" → replace with "Africa-first"
- ✗ "Offices in Southern Africa" → verify or remove
- ✗ "Regional SADC" → qualify or replace with "Regional Africa"

### Never Safe (Remove/Replace Immediately)
- ✗ Any claim of physical offices in SADC countries without evidence
- ✗ "global operations" without evidence of international delivery
- ✗ Any positioning that creates a geographic ceiling
