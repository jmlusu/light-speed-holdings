# Post 10: What Should an AI Agent Decide? - Governance (G) with Decision Rights Matrices - Carousel 2: Governance Escalation Flowchart for Agent Decisions

**Visual Description:** Flowchart showing the governance escalation process when AI agents face decisions beyond their autonomy level.

**Key Elements:**
- Top-down flowchart starting with "Agent Decision Request"
- Decision diamond: "Is autonomy level sufficient?"
- If "No": escalation path through tiers
- Escalation tiers matching the 5-tier matrix from Post 7:
  * Tier 1: Automated resolution attempt
  * Tier 2: Supervisor notification
  * Tier 3: Management review
  * Tier 4: Executive committee
  * Tier 5: Board-level intervention
- Each tier with: typical decision types, decision timeframes, success rates
- Arrow flows showing escalation progression
- LightSea brand colors for each escalation tier
- "Human override" button/indicator at each stage
- Title: "Governance Escalation Flowchart for AI Agent Decisions"

**Purpose:** Visualizes the step-by-step governance escalation process that activates when AI agent autonomy is insufficient for a given decision.
