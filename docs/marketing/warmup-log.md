## Shadowban / Throttling Detection

### Warning Signs (Check Daily)
- [ ] Post reach = 0 or near-0 for 2+ consecutive posts
- [ ] Sudden drop >80% in reach vs. previous average
- [ ] Hashtag search doesn't show your post
- [ ] "Account not found" in search
- [ ] Comments not visible to others

### If Detected
1. Stop posting 24-48 hours
2. Increase engagement (comment on others, no links)
3. Verify profile completeness
4. Check for policy violations
5. Resume with 1 post/day, monitor
