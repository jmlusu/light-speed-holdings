# SOP: Content Repurposing Waterfall Workflow
**Version:** 1.0
**Owner:** Marketing Owner
**Review:** Monthly
**Applies to:** All pillar content (Weeks 1-24+)

---

## Purpose
Transform ONE flagship pillar piece into 18+ platform-native assets using the Content Waterfall Method, ensuring brand compliance, SEO optimization, and consistent measurement.

---

| Role | Responsibilities |

## Waterfall Flow (Monday → Friday)

```
MONDAY          TUESDAY         WEDNESDAY       THURSDAY        FRIDAY
────────────────────────────────────────────────────────────────────────
CEO writes      Content team    Publish         Atomize to      Community
LinkedIn post   produces        pillar to       all platforms   engagement
(pillar)        video/asset     YouTube +       (waterfall)     (comments,
                                      Blog)                       replies)
```

## Step-by-Step Process

### Phase 1: Pillar Selection (Friday prior / Monday 8 AM)

**Input:** 90-day calendar (`content-calendar-90day.md`), keyword list (`keyword-master-list.md`)

**Actions:**
1. CMO confirms pillar theme + primary keyword for the week
2. Content Writer drafts CEO LinkedIn post outline (3 frameworks + 1 story)
3. Content Creator plans video shoot (shot list, locations, props)
4. Marketing Owner creates UTM spreadsheet for the week

**Output:** `pillar-{N}-week-{W}-brief.md` with:
- Pillar theme
- Primary + 3 secondary keywords
- CEO post angle
- Video concept
- Blog outline
- Asset checklist (18+ items)

---

### Phase 2: Asset Creation (Mon-Tue)

#### 2A. CEO LinkedIn Post (Monday 7 AM)
- **Owner:** CEO (or Thought Leadership Lead ghostwrite → CEO approve)
- **Length:** 1500-2000 words
- **Structure:** Hook → Framework → Proof → Principle → CTA
- **Brand:** No emojis, "ASPIRE. ACT. ACHIEVE." sign-off
- **Review:** 24-hr legal SLA if policy content

#### 2B. X Thread (Monday 7:30 AM)
- **Owner:** CEO / Content Writer
- **Length:** 8-10 tweets
- **Structure:** Same framework as LinkedIn, threaded
- **Visual:** Thread header image (template)
- **CTA:** Link to blog/YouTube in final tweet

#### 2C. Video Production (Tuesday)
- **Owner:** Content Creator
- **Format:** YouTube tutorial (10-15 min) + b-roll for Shorts
- **Shot List:** Hook → Problem → Solution → Demo → Results → CTA
- **Brand:** Lower-thirds (template), chapter markers, end-screen
- **Deliverables:** Raw footage → Edited long-form + 5 Short clips

#### 2D. Blog Post (Tuesday-Wednesday)
- **Owner:** Content Writer
- **Length:** 2000+ words
- **SEO:** Primary keyword in title/H1/first 100 words, H2/H3 structure, schema markup
- **Embed:** YouTube video + FAQ section
- **Internal Links:** 3+ to related pillars
- **Schema:** Article + VideoObject + FAQPage

---

### Phase 3: Hub Publication (Wednesday 8 AM)

**Owner:** Marketing Owner

**Publish Sequence:**
1. **YouTube Long-Form** → Schedule 10 AM CAT
   - Title: Primary keyword + benefit
   - Description: First 150 chars = answer + audience
   - Chapters: Match sub-questions
   - Tags: 10-15 (primary + secondary keywords)
   - End-screen: Subscribe + related video

2. **Blog Post** → Publish immediately
   - Canonical URL set
   - Social meta tags (OG, Twitter Card)
   - Video embedded at top
   - PDF download link (if applicable)

3. **UTM Tagging** → All links in descriptions/bio
   - Use convention from `analytics-setup.md`

#### Platform-Specific Rules

**TikTok:**
- Keyword in voiceover + on-screen text + caption (3 signals)
- Hook in first 1.5 seconds
- 3-5 niche hashtags only
- Video reply to comments in first hour

**Instagram Reels:**
- No TikTok watermark (re-edit in CapCut)
- 3-5 niche hashtags
- Cover uses Reels template
- DM-share worthy (educational/saveable)

**LinkedIn Carousels:**
- Native document upload (PDF)
- 5 slides: Hook → Framework → Proof → Application → CTA
- First slide = thumbnail in feed
- CEO comments within 1 hour

**YouTube Shorts:**
- Vertical 9:16, <60s
- Title = keyword phrase
- #Shorts hashtag
- Link to long-form in pinned comment

**X Thread:**
- 8-10 tweets, numbered
- Visual every 2-3 tweets
- External link in tweet 1 reply
- Retweet own thread at 5 PM

**Facebook Reels:**
- Cross-post from TikTok (re-edit if needed)
- Group post: Discussion question, not broadcast
- Tag relevant partners

## Quality Gates (Every Asset)

### Pre-Publish Checklist
- [ ] **Brand:** Colors, logo, typography, tagline per `TEMPLATE_SPECS.md`
- [ ] **SEO:** Primary keyword in title/first 100 words (blog/video)
- [ ] **UTMs:** All links tagged per convention
- [ ] **Accessibility:** Alt text on images, captions on video
- [ ] **Legal:** 24-hr review if policy/compliance content
- [ ] **Technical:** Video < 2MB (TikTok), < 100MB (YouTube), correct dimensions

### Post-Publish Verification (24h)
- [ ] No broken links
- [ ] Video plays correctly (all platforms)
- [ ] Carousel loads all slides
- [ ] Schema validates (Rich Results Test)
- [ ] UTMs firing in GA4 Real-time

## Naming Conventions

### Files
```
pillar{N}-week{W}-{platform}-{format}-{sequence}.{ext}
Examples:
pillar1-week1-youtube-long.mp4
pillar1-week1-tiktok-hook-01.mp4
pillar1-week1-linkedin-carousel-01.pdf
pillar1-week1-blog-agent-hierarchy.md
```

### Folders (Google Drive / Local)
```
/content/pillar1-week1/
  /source/          (raw footage, drafts)
  /youtube/         (long, shorts, thumbnails)
  /linkedin/        (carousels, article)
  /tiktok/          (5 videos)
  /instagram/       (reels, covers)
  /x/               (thread, header)
  /facebook/        (reels, group)
  /blog/            (markdown, images)
  /newsletter/      (section)
  /analytics/       (24h metrics)
```

## Exception Handling

| Scenario | Action |
|----------|--------|
| CEO unavailable | Thought Leadership Lead ghostwrites → CEO approves async |
| Video shoot delayed | Publish blog first → video follows within 48h |
| Legal blocks content | Pivot to technical pillar; reschedule policy |
| Platform outage | Cross-post to other platforms; resume when restored |
| Low asset quality | Re-create using template; don't publish off-brand |
