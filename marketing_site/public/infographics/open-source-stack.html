1Open-source-first toolchain → predictable cost architecture

In the markets we serve, the binding constraint is not the list price of a token. It is bandwidth, currency, and control. A toolchain built on permissive open source turns AI cost into an architectural choice rather than a vendor invoice: run models where the marginal token is free by design, rent open-weight APIs where host competition has already capped prices, and keep the operating skills portable across borders.

3The cost logic: mechanisms, not measurements

1 · Per-seat license drag avoided

The runtime path is one Python CLI + one FastAPI dashboard + one Vite/React SPA + Jinja2 generation, with no paid SaaS in the runtime path. Tooling that would otherwise be a per-seat subscription is a repository dependency instead.

Qualitative mechanism only. No dollar comparison between this stack and a licensed alternative is published here: no such measurement exists in-repo.

Sources: pyproject.toml · package.json · AGENTS.md §1

2 · Local inference at ledger convention "$0"

Models served through Ollama or llama.cpp carry no per-token charge, so cost_tracker.py prices them at zero. The in-code comment reads: "Ollama / local models — effectively free" (~line 64). The local option therefore reads as $0.00 marginal token cost by accounting convention.

This is a ledger convention, not a measured saving. No before/after billing evidence exists in-repo.

Source: src/ai_company/llm/cost_tracker.py (~line 64)

3 · Router prevents lock-in, enables cheapest-fit routing

ModelRouter routes across openai_compatible, ollama and llamacpp. Adding or swapping a provider is a config decision, not a code rewrite, so routing can follow whichever provider is cheapest or most reachable at the time, instead of being frozen into an integration.

Capability claim from code structure. No routed-spend data is published; monthly token volume and spend aggregates were not located in-repo.

Sources: src/ai_company/llm/client.py · src/ai_company/llm/providers/

4 · Open toolchain = skills transfer across the region

Python, ruff, mypy, bandit, FastAPI, React, Vite, Tailwind, Ollama and llama.cpp are the same tools used across the African developer ecosystem. The operating skills and the hiring pool that holds them do not expire with a vendor contract or a currency episode.

Qualitative. No measured skills-mobility or training-cost figure is claimed.

Sources: pyproject.toml · package-lock.json · .pre-commit-config.yaml · src/ai_company/llm/providers/

External market anchor

Since OpenAI put gpt-oss-20b under Apache 2.0 in August 2025, hosted versions trade at $0.075 per million input tokens on Groq ($0.30 output). 4Honest status

Savings percentages are not claimed: there are no measured client deployments yet. Honest status: proven in-house; no paid client deliveries yet.

This page argues from architecture and external price evidence, not from a measurement of our own spend. LightSpeed Holdings runs this toolchain in its own operations; the mechanisms, inventory and controls shown above are read from the repository. We do not publish a dollar figure saved against cloud APIs, a percentage cost reduction from local models, a cost per workflow, or a bandwidth saving. No measured before/after exists in-repo, and MODEL_COSTS is a pricing ledger, not billing evidence.

The single case pipeline on record (docs/Pharos/case-study-pipeline.md) is a real-SME engagement pipeline, not a revenue claim and not a client deployment claim. Where status cannot be established from evidence, we say so: AGENTS.md §15 (Evidence, Honesty and Execution Integrity Policy).

Numbers deliberately NOT asserted on this page (research-brief gap list)

  • Dollar savings vs cloud APIs, % cost reduction from local models, cost per workflow in USD.
  • Monthly token volume or spend aggregates.
  • Bandwidth-savings percentages; local-inference latency on regional hardware.
  • A live regression-test count (the 2,373 figure is dated 2026-09-10 and definition-dependent).
  • Offer pricing (MWK/USD): offer language only, not market-validated.
  • SADC readiness or AU strategy framing: proposal status only.
  • "Zero-cloud," "offline-first," or "SHA-256 audit trails" as operational guarantees: these are design/implementation claims, not externally audited guarantees.
