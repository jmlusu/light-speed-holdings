Review this session and separate ACTIVITY from RESULTS.

Provide exactly three sections:

### ACTIONS TAKEN
What the agent actually did.

### RESULTS ACHIEVED
What changed in the repository, application, infrastructure, tests, or deliverables as a result.

### NO RESULT / UNPROVEN
Actions that were attempted but produced no confirmed result, or claims that could not be verified.

Then provide:

**STATUS:** COMPLETE / COMPLETE WITH CONDITIONS / PARTIALLY COMPLETE / BLOCKED / FAILED

**EVIDENCE:** List the strongest evidence supporting the reported results.

**NEXT:** List only the actions required to finish the requested task.

Rules:
- Do not treat an action as a result.
- "Ran tests" is an action; "42/42 tests passed" is a result.
- "Reviewed files" is an action; "identified 7 duplicate configuration files" is a result.
- "Fixed the bug" is insufficient; identify the actual change and verification.
- Do not claim success without evidence.
