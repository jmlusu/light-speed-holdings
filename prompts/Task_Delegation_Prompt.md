Delegate this task to the maximum appropriate number of relevant agents/subagents available within the LightSpeed organization.

Use parallel execution where possible. Assign each agent a clearly defined role, scope, deliverable, and responsibility. Coordinate their work so they do not duplicate effort or conflict with each other.

Agents must:
- Read the relevant repository instructions, architecture, skills, and existing implementation before acting.
- Stay strictly within the requested task and its dependencies.
- Reuse existing patterns and components where appropriate.
- Investigate before changing; do not make speculative changes.
- Report findings, changes, blockers, and evidence back to the coordinating agent.
- Escalate conflicts or decisions that require CEO direction rather than silently changing scope.

The coordinating agent is responsible for consolidating the agents' work, resolving conflicts, verifying the complete task, and ensuring the requested outcome is actually implemented.

Do not expand the task into unrelated cleanup, refactoring, architecture changes, or feature work.

Before declaring completion, verify the implementation against the original task requirements and provide a concise CEO-readable status:
1. Completed
2. Not completed / blocked
3. Evidence of completion
4. Remaining actions
5. Any decisions requiring CEO approval
