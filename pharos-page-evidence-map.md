### 2. **5-Tier Human-in-the-Loop Approval System**

| Tier | Default | Timeout | Escalation | Governance Role |
|------|---------|---------|------------|-----------------|
| **T0 Auto** | Read, list, grep, recall | N/A | None | Most agent work |
| **T1 Notify** | Log only | N/A | Human sees history, never queue | Auditability |
| **T2 Single Approve** | One human operator | 60 min → escalate T3 | Request blocked until resolution | Budget <$100, config changes |
